Integrasi Hanya Dalam Hitungan Detik

Hanya butuh satu baris kode untuk mulai menarik data dari ZikAshmist API. Coba jalankan cURL ini di terminal Anda.

curl -X GET "https://api.zikashmist.com/v1/users" \
  -H "Authorization: Bearer YOUR_API_KEY"
// Response JSON
{
  "status": 200,
  "message": "Success",
  "data":[
    { "id": 1, "name": "ZikAshmist User" }
  ]
}
